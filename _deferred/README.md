# خدمات مؤجّلة — 007.gallery

أُخفيت ثماني خدمات من الموقع بتاريخ **2026-09-10**.

## لماذا؟

بطاقات «قريباً» تضرّ من وجهين:

1. **AdSense** — الخدمات غير الجاهزة سبب رفض شبه مؤكد. المراجع يرى موقعاً قيد الإنشاء.
2. **الانطباع** — ثماني بطاقات معطّلة مقابل سبع عاملة تجعل الموقع يبدو ناقصاً لا غنياً.

## المحفوظ هنا

`pro-services.json` — نصوص الخدمات الثماني كاملة (عربي/إنجليزي) وأسماء أيقوناتها.

## كيف تُرجع خدمة عند جاهزيتها

**لا تُرجع البطاقة قبل أن تعمل الأداة فعلاً.** الترتيب الصحيح:

1. ابنِ الأداة في `services/<اسمها>.html` وتأكد أنها تعمل.
2. أضف بطاقتها في `index.html` داخل `<div class="grid">` — انسخ شكل بطاقة موجودة:

```html
<a class="card" href="services/اسم-الأداة.html">
  <div class="ic"><!-- أيقونة SVG --></div>
  <h3><span data-ar>العنوان</span><span data-en>Title</span></h3>
  <div class="desc"><span data-ar>الوصف</span><span data-en>Description</span></div>
  <div class="go"><span data-ar>افتح الأداة</span><span data-en>Open tool</span> <span class="arrow">←</span></div>
</a>
```

3. حدّث العدد في الواجهة (`stats`) وفي نص الوصف.
4. أضف رابطها إلى `sitemap.xml`.

> **مهم:** البطاقات الآن **HTML ثابت** لا جافاسكربت — لأن محركات البحث يجب أن تراها.
> لا تُعِد نظام البناء بالجافاسكربت.
